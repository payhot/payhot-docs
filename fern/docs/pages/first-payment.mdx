## 1. Подготовьте запрос

Сумма передаётся строкой в минимальных единицах валюты. Для RUB значение `10000` означает `100,00 RUB`.

```bash
curl --request POST \
  --url 'https://app.pay.hot/api/v2/payments' \
  --header 'Authorization: Bearer <API-ключ>' \
  --header 'Idempotency-Key: order-1001-create' \
  --header 'Content-Type: application/json' \
  --data '{
    "merchant_order_reference": "order-1001",
    "amount_minor": "10000",
    "currency": "RUB",
    "payment_method": "sbp",
    "customer": {
      "id": "customer-1001"
    }
  }'
```

## 2. Откройте страницу оплаты

PayHot возвращает созданный платёж и ссылку на Checkout. Передайте эту ссылку плательщику или перенаправьте его в браузере.

## 3. Подтвердите результат

Статус создания подтверждает, что PayHot принял запрос. Итог платежа проверяйте через `GET /api/v2/payments/{payment_id}` или по подписанному вебхуку.

| Статус | Значение |
| --- | --- |
| `processing` | Платёж обрабатывается. |
| `authorized` | Средства авторизованы. |
| `succeeded` | Платёж успешно завершён. |
| `failed` | Платёж завершён с ошибкой. |
| `cancelled` | Платёж отменён. |

<Note>
Если провайдер окончательно завершил платёж с ошибкой или сообщил об истечении срока, PayHot также возвращает финальный статус ошибки.
</Note>
