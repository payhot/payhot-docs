Выплата создаётся через `POST /api/v2/payouts`. Сумма передаётся в копейках RUB.

## Реквизиты получателя

Реквизиты передаются только в запросе конкретной выплаты. Предварительно создавать или сохранять отдельный реквизит не требуется.

- Для карты передайте `recipient.method: card` и номер карты.
- Для СБП передайте `recipient.method: sbp`, телефон и идентификатор банка.

```json
{
  "merchant_payout_reference": "payout-1001",
  "amount_minor": "12000",
  "currency": "RUB",
  "recipient": {
    "method": "sbp",
    "phone": "+79991234567",
    "bank_id": "100000000001",
    "card_holder": "Иван Иванов",
    "payeer_identifier": "recipient-1001"
  }
}
```

## Статусы

| Статус | Значение |
| --- | --- |
| `processing` | Выплата принята и обрабатывается. |
| `succeeded` | Выплата выполнена. |
| `failed` | Выплата завершена с ошибкой. |
| `cancelled` | Выплата отменена. |

Ответ содержит один публичный статус выплаты. Внутренние этапы согласования и отправки PayHot не раскрываются.

<Warning>
Криптовалютные выплаты в публичном API пока недоступны.
</Warning>
