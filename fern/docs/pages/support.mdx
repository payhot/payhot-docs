Если запрос завершился ошибкой, сохраните `request_id` из ответа. Он помогает менеджеру PayHot найти операцию без передачи секретных данных.

Для связи откройте [бот поддержки PayHot](https://t.me/payhotsupport_bot).

Передайте менеджеру:

- `request_id`;
- время запроса и часовой пояс;
- путь API и HTTP-метод;
- ваш идентификатор заказа или выплаты;
- полученный код ошибки.

Не отправляйте API-ключ, полный номер карты, CVV или другие секреты.
