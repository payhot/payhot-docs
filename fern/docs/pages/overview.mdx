PayHot предоставляет единый публичный API для работы с проектом. Внешние особенности платёжных провайдеров остаются внутри PayHot.

## Базовый адрес

```text
https://app.pay.hot/api/v2
```

Все запросы отправляются по HTTPS. Тело запроса и ответа использует JSON.

## Авторизация

Передавайте API-ключ проекта в каждом запросе:

```http
Authorization: Bearer <API-ключ>
```

API-ключ связан с конкретным проектом и кассой. Создайте отдельный ключ для каждой интеграции и не передавайте его в браузер или мобильное приложение.

## С чего начать

1. Получите API-ключ в кабинете PayHot.
2. Создайте платёж через `POST /api/v2/payments`.
3. Перенаправьте плательщика по адресу из ответа.
4. Проверяйте итоговый статус платежа через API или подписанный вебхук.

<Tip>
Для операций создания используйте уникальный `Idempotency-Key`. При безопасном повторе отправляйте тот же ключ и то же тело запроса.
</Tip>

Выберите нужный метод в меню слева. На странице метода доступны параметры, примеры запросов, ответы и интерактивная проверка.
